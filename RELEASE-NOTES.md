# Paddock 1.1.0

Paddock is the new name for Slice. It now has the Sedge look shared by every webhookstudios app: one set of colors, fonts and icons, in light and dark mode.

- New icon, colors and fonts. Window titles and headings use the Sedge serif.
- **The package is now called `paddock`**, and so is the command. `slice` is also the name of an unrelated Ubuntu text tool, so the two could not be installed together, and app libraries could mistake one for the other. Installing `paddock` replaces the old `slice` package (1.0.x) and never touches Ubuntu's tool.
- Everything works exactly as before. Your settings and presets carry over.

Install:

```bash
sudo apt install ./paddock_1.1.0_all.deb
```
